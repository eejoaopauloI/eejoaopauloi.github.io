⚖️ Por que uma equação se parece com uma balança?

Imagine duas bandejas com a mesma massa. Uma balança equilibrada nos diz que o peso total do lado esquerdo é igual ao do lado direito. Em Matemática, o sinal = também afirma que os valores dos dois lados são iguais.

1. O que é uma igualdade?
3 + 4 = 7

O sinal = não quer dizer “agora calcule”. Ele afirma que 3 + 4 e 7 representam a mesma quantidade.

2. O que é uma equação?
x + 3 = 7

É uma igualdade com uma incógnita: uma letra que representa um valor que queremos descobrir. Aqui, x = 4, pois 4 + 3 = 7.

📘 Por que fazemos operações nos dois membros?

1Subtrair: retiramos a mesma quantidade de ambos os lados para eliminar pesos que acompanham x. Ex.: x + 3 = 7 → x = 4.
2Adicionar: quando falta uma quantidade em um membro, somamos o mesmo número aos dois. Ex.: x − 2 = 5 → x = 7.
3Dividir: se há várias caixas idênticas, repartimos os dois membros pelo mesmo número diferente de zero. Ex.: 2x = 8 → x = 4.
4Multiplicar: se uma fração de caixa representa uma quantidade, multiplicamos os dois lados pelo mesmo número diferente de zero. Ex.: x/2 = 4 → x = 8.
Exemplo completo: 2x + 4 = 12.
Retiramos 4 de cada lado: 2x = 8.
Dividimos ambos os membros por 2: x = 4.
Conferência: 2 · 4 + 4 = 12. Os dois lados continuam iguais!

    📒 Síntese para o caderno e orientações de estudo

    1. O que significa uma equação?

    Uma equação é uma igualdade que contém um valor desconhecido, representado por uma letra. Na equação x + 3 = 7, o valor de x é 4, porque 4 + 3 = 7.

    2. O princípio da balança

    Se dois pratos têm a mesma massa, retirar a mesma quantidade dos dois mantém o equilíbrio. Do mesmo modo, podemos somar ou subtrair o mesmo número dos dois lados de uma equação; também podemos multiplicar ou dividir os dois membros pelo mesmo número não nulo.

    3. Como isolar x?

    Em 2x + 4 = 12, retire 4 unidades de ambos os lados: 2x = 8. Depois divida ambos os lados por 2: x = 4. Confira substituindo 4 na equação original: 2 · 4 + 4 = 12.

    4. E quando há x nos dois pratos?

    Em 3x + 2 = x + 10, retire uma caixa x de cada lado: 2x + 2 = 10. Retire 2 unidades de ambos os lados: 2x = 8. Divida por 2: x = 4.

    5. Exercícios para registrar no caderno

    Resolva mostrando cada operação nos dois membros: (a) x + 5 = 11; (b) x + 8 = 15; (c) 3x = 18; (d) 4x = 28; (e) 2x + 3 = 17; (f) 5x + 2 = 22; (g) 3x + 4 = x + 12; (h) 4x + 5 = 2x + 17. Confira cada resultado por substituição na equação original.
